# Mnemosift — ローカルAIワークスペース (macOS / Apple Silicon)

**「会議も、ファイルも、メモも。すべて自分のPC内でAIが整理する。」**

Mnemosift は、macOS (Apple Silicon) 上で音声認識（STT）、専門用語・文脈補正（System One 判断モデル & LLM）、議事録生成、ファイル分類・整理、ハイブリッド意味検索（FTS5 + Embedding RAG）を完全ローカル・オフラインで実現するデスクトップアプリケーションです。

---

## 主な特徴

1. **ローカルファースト & プライバシー保護**
   - 音声・文字起こし・議事録・登録文書はすべてローカルの SQLite（WALモード + FTS5 + ベクトルインデックス）および管理ディレクトリに保存され、外部APIへ一切送信しません。
2. **4分類マルチAIモデル管理 (`ModelManager`)**
   - **STT**: `Qwen3-ASR 0.6B / 1.7B`, `Whisper Large v3 Turbo (WhisperKit)`, `Apple SpeechAnalyzer`, `kotoba-whisper`
   - **判断モデル (System One)**: `Japanese ModernBERT Classifier`, `GLiFormer`, `Apple NaturalLanguage + 音韻距離判定器`
   - **LLM**: `Gemma 4`, `Qwen 2.5 7B`, `内蔵ローカル構造化エンジン`
   - **Embedding**: `EmbeddingGemma 2`, `Apple NLEmbedding Hybrid 256d`
   - 設定の優先順位（**1. 実行時の個別指定 → 2. プロジェクト固有設定 → 3. アプリ全体設定**）を自動解決します。
3. **非同期リアルタイム文字起こし & 4段階補正モード (`STTService` / `CorrectionService`)**
   - 録音保存とSTT/AI補正を完全分離し、AI処理が遅延しても録音を失いません。
   - **モード1（補正オフ）** / **モード2（辞書補正）** / **モード3（高速AI補正：判断モデル）** / **モード4（高精度AI補正：LLM）** を切り替え可能。
   - **STT原文 (`rawText`) と補正結果 (`correctedText`) を分離保存**し、否定表現・数値・日付の改変を防ぐガードレールと、ワンクリックのロールバック（誤補正取り消し）を備えています。
4. **プロジェクト文脈・専門用語辞書 (`ProjectService`)**
   - プロジェクト未所属の単発処理も正式データとして扱い、後から複数プロジェクトへ関連付け可能。
   - 手動登録・文書からのAI抽出・過去議事録からのAI抽出・補正履歴からの候補生成の4経路に対応し、AI抽出用語は「候補（承認待ち）」として登録されます。
5. **議事録生成・部分再生成 (`LLMService`)**
   - 標準議事録・技術会議・要点のみ・決定事項/TODO中心の4標準テンプレート＋カスタムテンプレートに対応。
   - 担当者・期限が発言内で明確でない場合は推測で確定せず「未定」として記録します。
6. **段階的ファイル分類 & 承認制ファイル整理 (`DocumentService`)**
   - **ルール → Embedding → 小型判断モデル → LLM** の段階的パイプラインにより、軽量処理で判断可能な場合は大型LLMを起動しません。
   - リネーム・フォルダ移動等の破壊的操作は必ずユーザー承認後に適用し、`FileOperationHistory` からいつでも元に戻せます（ロールバック）。
7. **3モードAI検索・マルチファクターRAGチャット (`SearchService`)**
   - **全体検索** / **プロジェクト優先検索** / **プロジェクト限定検索** を明確に区別。
   - 意味的類似度・FTS5キーワード・鮮度減衰・重要度を考慮し、古い資料がプロジェクト一致だけで不当に優先されることを防ぎます。

## ビルド・実行・テスト方法

### アプリの起動
```bash
swift run Mnemosift
```

### 総合テスト・Phase 0 技術検証スイートの実行
```bash
swift test
```
